# Backend

NestJS REST API for the e-commerce platform.

## Quick Start

```bash
npm install
docker compose up -d    # Redis + RabbitMQ
npm run start:dev       # http://localhost:3005/api
```

Create a `.env` file before starting — see the [Setup Guide](../docs/SETUP.md).
