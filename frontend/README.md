# Frontend

Next.js 14 storefront and admin dashboard.

## Quick Start

```bash
npm install
npm run dev    # http://localhost:3000
```

Create `.env.local` with:

```env
NEXT_PUBLIC_BACKEND_URL=http://localhost:3005/api
```

See the [Setup Guide](../docs/SETUP.md) for details.
